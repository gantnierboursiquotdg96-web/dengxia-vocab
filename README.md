# 灯下词境

在故事里遇见单词。

四级原创连载《把你留在有光的地方》共61章，正文覆盖本项目所用来源词表的4424个规范词头。网站保留《借灯人》体验篇，并分别提供四级、六级、考研和雅思来源词库。

## 阅读功能

- 章节目录、带释义阅读、隐藏释义和中文释义替换。
- 语境词卡、来源音标、词汇检索、收藏和回到原文。
- 本书阅读进度与收藏保存在访问者自己的浏览器中；不需要登录ChatGPT。
- 体验篇保留原有听读和练习。词汇出现不等于学习者已经掌握。

## GitHub Pages

本仓库是静态站点。将 `main` 分支的根目录设为 Settings → Pages → Deploy from a branch 的发布来源即可。`.nojekyll` 保持静态文件原样发布。

网站首页为 `index.html`，完整四级小说入口为 `books/cet4-lost-found/index.html`。路径保持相对形式，兼容GitHub Pages的仓库子路径。

词汇、音标与发音资料的来源说明保留在相应页面和 `vocab/pronunciation-licenses/` 中。
